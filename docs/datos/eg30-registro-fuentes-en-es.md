# EG-30 — Data source register / Registro de fuentes de datos

**Status / Estado:** Working draft. Provider and monthly closing policy require ADR-0021 approval. Live HTTP and database acceptance evidence is pending.

## English

| ID | Type and owner | Endpoint / origin | Fields used | Update cadence and notes |
| --- | --- | --- | --- | --- |
| F5 | **Synthetic**, generated by SonoraPlay (not an external advertising API) | `src/sonoraplay/fuentes/f5_publicidad.py` | `mes, pais, moneda, ingresos_publicidad` | Reproducible monthly CSV using fixed seed 2026; six country rows (AR, BR, CL, CO, MX, PE). Values are fictional and **must not be presented as actual ad revenue**. |
| F6 | **External**, Frankfurter v2, blended exchange rates aggregated from providers | `https://api.frankfurter.dev/v2/rates` | `date, base, quote, rate`; normalized `moneda, fecha, fecha_observacion, unidades_por_usd, proveedor` | Historical daily observations and calendar month-end derived by project policy. USD base; ARS, BRL, CLP, COP, MXN, PEN quotes. No API key stated by provider. These are blended rates, not guaranteed national official settlement rates. |
| F7 | **External**, REST Countries reference dataset | `https://restcountries.com/v3.1/all?fields=cca2,name,region,currencies` | `cca2, region, currencies`; normalized `pais, region, monedas` | Country reference data; refresh per ingestion run. Approx. 250 countries requested by Jira, but code currently only enforces at least 200. Actual count and current access/authentication conditions must be verified live. |

### Reproducibility and licensing
- Record extraction timestamp, HTTP status, actual response date, provider attribution and dataset version when available. F6's proposed `extraido_en_utc` is currently recorded in PostgreSQL ingestion, but not yet in all exported JSON artifacts.
- **Do not treat provider documentation as proof that the six required quotes or ~250 country records were retrieved.** Save a dated real-response validation before accepting EG-30.
- Frankfurter documentation: https://frankfurter.dev/ ; providers and attribution: https://frankfurter.dev/providers/
- REST Countries: https://restcountries.com/ ; reference field definitions: https://gitlab.com/restcountries/restcountries/-/blob/master/FIELDS.md
- Review the providers' current terms, attribution and rate limits before distributing or publishing datasets. No paid subscription or cloud service is authorized by this document.
- ADR-0021 (proposed): `docs/adr/0021-f6-fuentes-tasas-cierre-propuesto.md`.

### Reproducibilidad y licencias
- Registrar momento de extracción, código HTTP, fecha real de observación, atribución y versión cuando exista. `extraido_en_utc` se guarda en PostgreSQL, pero aún no en todos los JSON exportados.
- **La documentación del proveedor no demuestra que ya se hayan obtenido las seis monedas ni unos 250 países.** Es necesario guardar evidencia fechada de una consulta real.
- Documentación Frankfurter: https://frankfurter.dev/ ; atribución: https://frankfurter.dev/providers/
- REST Countries: https://restcountries.com/ ; definición de campos: https://gitlab.com/restcountries/restcountries/-/blob/master/FIELDS.md
- Revisar términos de uso, atribución y límites vigentes antes de redistribuir datos. Este documento no autoriza suscripciones pagas ni servicios de nube.
- ADR-0021 pendiente: `docs/adr/0021-f6-fuentes-tasas-cierre-propuesto.md`.
